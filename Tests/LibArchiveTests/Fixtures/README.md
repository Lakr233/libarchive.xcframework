# Fixtures

Formats libarchive can read but not write, so a round trip cannot cover them.
Everything libarchive can also write is generated by the tests instead.

Taken from libarchive's own test suite (BSD-2-Clause, the same licence as
libarchive itself) and uudecoded from `libarchive/test/*.uu`. The smallest file
that exercises each reader was chosen.

| File | Bytes | Source |
| ---- | ----: | ------ |
| `rar4.rar` | 336 | `test_read_format_rar.rar.uu` |
| `rar5.rar` | 109 | `test_read_format_rar5_stored.rar.uu` |
| `cab.cab` | 266 | `test_read_format_cab_1.cab.uu` |
| `lha.lzh` | 434 | `test_read_format_lha_lh0.lzh.uu` |
| `cpio.rpm` | 1909 | `test_read_format_cpio_svr4_gzip_rpm.rpm.uu` |

`cpio.rpm` is the only one over 1 KB; an RPM cannot be smaller, its header
alone accounts for most of it. It covers the rpm filter, which strips that
header to reach a gzipped SVR4 cpio underneath.
